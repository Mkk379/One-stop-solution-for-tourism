# One Stop Tourism (Android)

Hotels, events and cabs in one app. Local SQLite database, no backend or API keys needed.

## Run
1. Install Android Studio (Hedgehog 2023.1+ recommended; JDK 17 is bundled).
2. File > Open > select this folder, wait for Gradle sync to finish.
3. Pick an emulator or a USB-connected phone and press Run.

## Roles
| Role | What they can do |
|---|---|
| Admin (admin@tourism.com / admin123) | Add hotels, events, cabs; delete any listing; see and manage all bookings |
| Tourist / User | Browse hotels, events, cabs; book; track My Bookings |
| Hotel Owner / Event Organizer / Cab Operator | Add their own listings; view and confirm/cancel bookings received |

Register new accounts from the login screen. Sample listings are pre-loaded.
To reset all data: uninstall the app (or Clear storage) and run again.
